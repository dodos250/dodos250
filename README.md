## What I'm building

* **[RURIMI](https://github.com/rurimi-ai)** — a computational lexicon and language engine for Kinyarwanda that represents and restores **tone and vowel length**, the two features ordinary spelling leaves out.
* **IJWI** — RURIMI's Kinyarwanda annotation engine for tone, vowel length, and word-form analysis.

Live demo: **[main.rurimi.pages.dev](https://main.rurimi.pages.dev)**
